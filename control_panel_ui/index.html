Providerها

وضعیت Runtime هر مقصد Web Chat.

ترافیک واقعی Web Chat

فقط درخواست‌هایی که به یک Provider انتخاب‌شده ارسال شده‌اند؛ Polling پنل و Health شمرده نمی‌شوند.

عملکرد Providerها در یک ساعت اخیر

درخواست، موفق/ناموفق، تأخیر، آخرین فعالیت و توکن اندازه‌گیری‌شده.

زنجیره آماده‌سازی Web Chat

۱. Profileمحل هویت و Session مرورگر
۲. Browser RuntimeChrome/CDP با Profile مشخص
۳. Loginورود به Web Chat در همان Profile
۴. Providerاتصال منطقی HWG به Runtime
۵. Enable & Testفعال‌سازی و آزمون نهایی

Runtimeهای مرورگر

عملیات Start / Open فقط اینجا انجام می‌شود. Provider صفحه مدیریت منطقی است، نه کنترل Browser.

پروفایل‌های مرورگر

Profile یک Chrome user-data directory است؛ Cookie، Login Session، Local Storage و تنظیمات مرورگر بعد از اجرای Chrome در آن ذخیره می‌شوند. Profile تازه در ابتدا تقریباً خالی است.

پراوایدرهای ثبت‌شده

این صفحه فقط تنظیمات منطقی Provider را مدیریت می‌کند. Browser/Profile در «مرورگر و اتصال» مدیریت می‌شود.
